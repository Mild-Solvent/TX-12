//   = <n> <Name>|<Difficulty>[|<Tribute>]   starts level n; this becomes the file's first line
//                               (Tribute: the official level it is modelled on, shown in the picker)
//   ! <u> <tune>                music: seconds per unit, then tokens (C42 = C4 for 2 units, R1 = rest)
//   ~<N>                        N empty columns
//   // ...                      comment
//   anything else               a segment: up to 20 lines of tiles, top row first, bottom-aligned
//                               (a level gets as many rows as its tallest segment, at least 6)
//                               (" " or "." = empty); a blank line ends the segment
// A tile line must not start with "= ", "! ", "~" or "//" (start it with "." instead).
//
// Tiles (one character per 8x8 cell; full table at the top of GDASH/phys.lua):
//   # block  = slab  ^ spike  v hanging spike
//   slopes: / up 45  ` down 45  ( ) gentle up (low, high half)  [ ] gentle down (high, low half)
//   orbs (press): o yellow  i pink  r red  q blue(flip)  e green(flip+jump)  b black(down)
//                 a green dash  h pink dash (hold to dash)
//   pads (touch): p yellow  k pink  f red  u blue(flip)  w spider
//   portals (whole column): C cube  U ufo  S ship  B ball  W wave  R robot  X spider  Z swing
//                 G/g gravity up/down  m/n mini/normal  D/d dual/single  T teleport (to the t
//                 in the same column)  t teleport exit  0-4 speed 50/70/90/110/130 px/s
// Output rows are run-length coded ("c*N" = c repeated byte(N)-32 times) unless --plain.
//
// The stock levels (L1-L8) are 60-90 s long and 9-12 rows tall, built like real Geometry Dash levels:
// an intro cube part, mode sections through portals, drops where the music peaks,
// short breathers. "// m:ss" comments give the time each part starts (at its speed).
// Each tune is written so that at the level's main speed one column = one unit.
