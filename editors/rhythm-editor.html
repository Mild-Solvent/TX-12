    Help

    How the game reads a song
    • File RHYTHM/s<n>.lua, first line -- @Name|Difficulty (shown in the picker), then return { u = …, a = …, m = "tokens…" }.
    • Token = note name (C C# D D# E F F# G G# A A# B, no flats) + octave digit + length digit (1-9 units of u seconds) + optional mark: none = tap circle, h = hold, s = slider, x = played but not charted. R<n> = rest.
    • Every charted note is a circle hit at its start time. Holds/sliders end at start + len − min(0.3, len/4) seconds.
    • Windows: 300 = ±0.10 s, 100 = ±0.18 s, 50 = ±0.26 s, later = miss. Slider: off the ball (13 px) for >0.2 s caps it at 100, >0.45 s = miss. Releasing a hold early = miss.
    • Circle positions are not in the file: the game places each one 18-40 px from the previous one with a fixed seed (file number × 1013 + 7), avoiding circles still on screen. So the same song gets different positions under another file number, and positions can shift a little with how you play (hit circles leave the screen sooner). The preview runs the game's own algorithm with the chosen play model; play-test runs it live.
    • The format has no explicit x/y positions, so the editor cannot move circles by hand. Change the note timing or the file number to get a different layout.
    Adding the song to the radio
    • Save as the next free number: s6.lua, s7.lua, … (the game counts s1, s2, … until one is missing, max 99). No game change needed. A gap (e.g. s8 without s7) hides everything after it.
    • Copy to the SD card as /SCRIPTS/GAMES/RHYTHM/s<n>.lua. If you replace an existing file, delete its s<n>.luac.
    • Best scores in rhythm.dat are stored by number, so replacing s3 keeps s3's old best score.
    Keys
    • Space play/stop · Home to start · ←→ select prev/next · ↑↓ pitch (Shift = octave)
    • 1-9 length · T tap H hold S slider X music only · N add note · R add rest · B file line break after · Del delete (leaves silence) · Ctrl+Z/Ctrl+Y
    • Ctrl+C copy · Ctrl+X cut · Ctrl+V paste after the selection (or at the playhead), overwriting that stretch · Ctrl+A select all
    • Roll: left click adds, right click deletes, drag moves, right edge resizes, Shift+drag box-selects. A token is at most 9 units long; for a longer sound put a music-only (x) note of the same pitch right after it.
    • Work is autosaved in this browser.
